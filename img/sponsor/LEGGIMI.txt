Tutti ridimensionati a 144px: e' il triplo del riquadro da 48px, cioe'
quello che serve per restare nitidi sugli schermi Retina.

Per SOSTITUIRNE uno, salva il nuovo file con lo stesso nome esatto.

Regole pratiche:
- Immagine quadrata (es. 200x200 px), sfondo trasparente se possibile.
- Il logo viene rimpicciolito dentro un riquadro di 48x48 px, quindi
  evita loghi con scritte lunghe e piccole: si leggerebbero male.
- Se un file manca, la scheda resta com'e' oggi (sigla + nome + sconto):
  non compare nessun quadrato vuoto. Puoi quindi aggiungerli uno alla volta.
- Se vuoi usare .jpg o .webp invece di .png devi cambiare il nome del file
  anche dentro index.html, nella sezione SUPPORTAMI.
